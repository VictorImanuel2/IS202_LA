# Krisestøtte-portalen

Krisestøtte-portalen er en kriseberedskapsportal for Totalforsvaret som skal koble behov fra offentlige aktører med ressurser fra innbyggere og næringsliv.

## Kom i gang

1. Kopier `.env.example` til `.env`: `cp .env.example .env`.
2. Start miljøet med `docker compose up --build`.
3. Webappen er tilgjengelig på port 8080 (`http://localhost:8080`).
4. MariaDB er tilgjengelig på port 3306.
